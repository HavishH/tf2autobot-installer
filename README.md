# TF2Autobot Installer

A one-command installer for TF2Autobot.

This installer automatically installs the required dependencies, downloads TF2Autobot, builds it, and prepares it for configuration.

> Linux support may be added in the future.

## Installation

Run the following command in PowerShell:

```powershell
irm https://raw.githubusercontent.com/HavishH/tf2autobot-installer/main/installer-windows.ps1 | iex
```
